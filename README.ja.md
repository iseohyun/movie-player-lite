# 🎬 Movie Player Lite

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | **日本語** | [Español](README.es.md) | [Português](README.pt-BR.md) | [Deutsch](README.de.md)

動画を見ながら、**必要な部分だけを画質を落とさず一瞬で切り出せる** Windows 用の無料動画プレーヤーです。

---

## ⬇️ ダウンロードとインストール

### 👉 [Movie Player Lite のインストーラーをダウンロード（Windows 10 / 11）](https://github.com/iseohyun/movie-player-lite/releases/latest/download/MoviePlayerLite-Setup.exe)

1. **上のリンクをクリックします。** `MoviePlayerLite-Setup.exe` というファイルがダウンロードされます。
2. **ダウンロードしたファイルをダブルクリックします。** 通常は「ダウンロード」フォルダーにあります。
3. 青い **「Windows によって PC が保護されました」** という画面が出たら、**詳細情報** → **実行** をクリックします。
   個人が作ったプログラムに対して表示される案内で、プログラムに問題があるという意味ではありません。
4. 言語を選び、**次へ** を押して進めます。途中の選択項目はそのままで構いません。

   | 選択項目 | 説明 |
   | :--- | :--- |
   | インストール先フォルダー | 特に理由がなければそのままにします。 |
   | デスクトップにショートカットを作成 | デスクトップにアイコンが欲しい場合にチェックします。 |
   | 既定で再生するファイルの種類 | チェックした種類（`.mp4` など）は、ダブルクリックするとこのプログラムで開きます。 |
   | 最新の FFmpeg をダウンロード | **チェックしたままにしてください。** カットと YouTube 動画の保存に必要な部品を自動で取得します。すでにある場合、この項目は表示されません。 |

5. **インストール** を押してしばらく待ち、**完了** を押すとプログラムが起動します。

- 管理者権限は不要です。64 ビット版 Windows 10 / 11 で動作します。
- **アンインストールするには**、Windows の「設定」→「アプリ」→「インストールされているアプリ」で **Movie Player Lite** を探し、「アンインストール」を押します。

## 🎞️ できること

- **画質を落とさない超高速カット** — 再エンコードしないので、長い動画でも数秒で終わります。
- **画面を回転・反転して保存**、**現在の場面をスクリーンショットとして保存**
- **画面の上に描く** — ペンで描いた線はしばらくすると消えます。説明しながら見るときに便利です。
- **YouTube のアドレスで再生** — 初回はすぐにストリーミング再生し、次回からは保存したファイルを再生します。
- **再生速度、拡大・移動、コマ送り、プレイリスト**
- **7 言語** — 한국어、English、简体中文、日本語、Español、Português、Deutsch

## 🚀 はじめての使い方

**動画を開く**
動画ファイルをプログラムのウィンドウにドラッグ＆ドロップします。または画面を右クリックして「ファイル」→「開く」を選びます。

**必要な区間を切り出す**
1. `E` キーを押して編集パネルを開きます。
2. 下のタイムラインにある **緑色の線 2 本** をドラッグして、開始位置と終了位置を決めます。
3. **カット** ボタンを押します。元のファイルはそのまま残り、切り出したファイルが新しく作られます。

**YouTube の動画を見る**
`Ctrl + U` を押して YouTube のアドレスを貼り付けます。視聴する権利のある動画にのみ使用してください。

**メニューを表示する**
`Alt` キーを押すか、画面を右クリックします。メニュー項目の右側にショートカットが表示されます。

## ⌨️ よく使うショートカット

| 機能 | ショートカット |
| :--- | :---: |
| 再生 / 一時停止 | `Space` |
| 1 秒戻る / 進む | `←` / `→` |
| 5 秒戻る / 進む | `Shift + ←` / `Shift + →` |
| 1 フレーム戻る / 進む | `<` / `>` |
| 音量を上げる / 下げる | `↑` / `↓` |
| ミュート | `M` |
| 速く / 遅く / 標準速度 | `+` / `-` / `0` |
| 全画面 / 終了 | `F` / `Esc` |
| 編集（カット）パネル | `E` |
| プレイリスト | `L` |
| YouTube のアドレスを開く | `Ctrl + U` |
| 画面を回転（右 / 左） | `]` / `[` |
| 拡大 / 縮小 / 元に戻す | `Ctrl + +` / `Ctrl + -` / `Ctrl + 0` |
| 回転した動画を保存・スクリーンショット | `Ctrl + S` |
| 描画のオン/オフ / すべて消去 | `D` / `C` |
| 前の動画 / 次の動画 | `PgUp` / `PgDown` |
| プログラム情報 | `F1` |

すべてのショートカットは「設定」→「ショートカット」で検索・変更できます。

## 🌐 言語の変更

「設定」→「言語」で選びます。選ぶとプログラムが再起動し、すぐに反映されます。最初は Windows の言語に従います。

## ❓ よくある質問

**「Windows によって PC が保護されました」という画面が出ます。**
有料の証明書で署名されていないプログラムに対して Windows が表示する案内です。**詳細情報** → **実行** をクリックするとインストールできます。

**FFmpeg とは何ですか？ 必要ですか？**
動画を切ったりつないだりする無料のツールです。なくても再生はできますが、カットと YouTube 動画の保存ができません。インストール時にチェックしたままにしておけば自動で取得されます。

**YouTube の動画が開けません。**
YouTube 側の仕様変更で一時的に開けなくなることがあります。上のリンクから最新のインストーラーをダウンロードして、もう一度インストールしてみてください。

**保存した YouTube 動画はどこにありますか？**
`%APPDATA%\MP4-Trim\youtube_cache` フォルダーにあります。エクスプローラーのアドレスバーにそのまま貼り付けると開きます。容量が大きくなったら、このフォルダー内のファイルを削除してください。

**アンインストールすると自分の動画も消えますか？**
いいえ。削除されるのはプログラムだけで、動画ファイルや切り出したファイルはそのまま残ります。

## 🛠️ 開発者向け

<details>
<summary>ソースから実行・ビルドする</summary>

必要なもの: Python 3.12、`pip install PyQt6 yt-dlp pyinstaller`、PATH 上の FFmpeg

```
python movie-player-lite.py      ソースからそのまま実行
.\run-dev.bat                    実行中のアプリを終了 -> 再ビルド -> 起動
.\build-installer.bat            インストーラーを作成（Inno Setup 6 が必要）
```

- インストーラーは `installer_output\MoviePlayerLite-Setup.exe` に作成されます。同じ名前で GitHub のリリースにアップロードすると、この文書のダウンロードリンクが最新版を指すようになります。
- インストーラーに表示されるバージョンは `VERSION.md` の一番上の項目から読み取ります。
- **言語の追加**: `locales/en-US.json` を `locales/<言語コード>.json` としてコピーして翻訳し、`_meta.name` に表示名、`_meta.fonts` にその言語の文字を表示できるフォントを書くと、メニューに自動で表示されます。

```
src/core/       コアロジック（カットとメタデータ、ショートカット、多言語、YouTube）
src/ui/         画面（メインウィンドウ、プレーヤーとタイムライン、ダイアログ、フォント）
locales/        言語ごとの翻訳ファイル
installer.iss   インストーラーのスクリプト
```

</details>
