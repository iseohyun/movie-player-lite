# 🎬 Movie Player Lite

[English](README.md) | **한국어** | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [Español](README.es.md) | [Português](README.pt-BR.md) | [Deutsch](README.de.md)

동영상을 보다가 **필요한 구간만 화질 손실 없이 순식간에 잘라 내는** Windows용 무료 동영상 플레이어입니다.

---

## ⬇️ 내려받기와 설치

### 👉 [Movie Player Lite 설치 파일 받기 (Windows 10 / 11)](https://github.com/iseohyun/movie-player-lite/releases/latest/download/MoviePlayerLite-Setup.exe)

1. **위 링크를 누릅니다.** `MoviePlayerLite-Setup.exe` 파일이 내려받아집니다.
2. **내려받은 파일을 더블클릭합니다.** 보통 `다운로드` 폴더에 있습니다.
3. 파란색 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
   개인이 만든 프로그램이라 뜨는 안내이며, 프로그램에 문제가 있다는 뜻은 아닙니다.
4. 설치 화면에서 언어를 고르고 **다음**을 눌러 진행합니다. 중간에 나오는 선택 항목은 그대로 두셔도 됩니다.

   | 선택 항목 | 설명 |
   | :--- | :--- |
   | 설치 폴더 | 바꿀 필요가 없으면 그대로 둡니다. |
   | 바탕화면 바로가기 만들기 | 바탕화면에 아이콘이 필요하면 체크합니다. |
   | 기본 재생할 파일 형식 | 체크한 형식(`.mp4` 등)의 파일을 더블클릭하면 이 프로그램으로 열립니다. |
   | 최신 FFmpeg 내려받기 | **체크된 채로 두세요.** 자르기와 유튜브 저장에 필요한 부품을 자동으로 받습니다. 이미 있으면 이 항목은 나오지 않습니다. |

5. **설치**를 누르고 기다린 뒤 **마침**을 누르면 프로그램이 실행됩니다.

- 관리자 권한이 필요 없습니다. 64비트 Windows 10 / 11에서 동작합니다.
- **삭제하려면** Windows `설정` → `앱` → `설치된 앱`에서 **Movie Player Lite**를 찾아 `제거`를 누릅니다.

## 🎞️ 할 수 있는 일

- **화질 손실 없는 초고속 자르기** — 다시 인코딩하지 않아 긴 영상도 몇 초면 끝납니다.
- **화면 회전·반전 후 저장**, **현재 장면 스크린샷 저장**
- **화면 위에 그리기** — 펜으로 표시하면 잠시 뒤 사라집니다. 설명하면서 볼 때 편합니다.
- **유튜브 주소로 재생** — 처음에는 바로 스트리밍하고, 다음부터는 저장해 둔 파일로 재생합니다.
- **재생 속도, 확대·이동, 한 프레임씩 이동, 재생목록**
- **7개 언어** — 한국어, English, 简体中文, 日本語, Español, Português, Deutsch

## 🚀 처음 사용하기

**동영상 열기**
동영상 파일을 프로그램 창에 끌어다 놓습니다. 또는 화면을 마우스 오른쪽 버튼으로 눌러 `파일` → `열기`를 고릅니다.

**원하는 구간 자르기**
1. `E` 키를 눌러 편집 창을 엽니다.
2. 아래 타임라인의 **초록색 선 두 개**를 끌어 시작과 끝을 정합니다.
3. **컷팅** 버튼을 누릅니다. 원본은 그대로 두고 잘라 낸 파일이 새로 만들어집니다.

**유튜브 영상 보기**
`Ctrl + U`를 누르고 유튜브 주소를 붙여 넣습니다. 본인이 볼 권리가 있는 영상에만 사용하세요.

**메뉴 보기**
`Alt` 키를 누르거나 화면을 마우스 오른쪽 버튼으로 누릅니다. 메뉴 오른쪽에 단축키가 함께 표시됩니다.

`설정` → `언어`에서 고릅니다. 고르면 프로그램이 다시 시작되면서 바로 적용됩니다. 처음에는 Windows 언어를 따릅니다.
다른 언어의 글자를 표시하려고 Windows 언어 팩을 추가로 설치할 필요는 없습니다.

## ❓ 자주 묻는 질문

**"Windows의 PC 보호" 창이 떠요.**
유료 인증서로 서명하지 않은 프로그램에 Windows가 띄우는 안내입니다. **추가 정보** → **실행**을 누르면 설치됩니다.

**FFmpeg가 뭔가요? 꼭 받아야 하나요?**
동영상을 자르고 합치는 무료 도구입니다. 없으면 재생은 되지만 자르기와 유튜브 저장이 되지 않습니다. 설치 중에 체크만 해 두면 자동으로 받습니다.

**유튜브 영상이 안 열려요.**
유튜브가 구조를 바꾸면 일시적으로 안 될 수 있습니다. 위 링크에서 최신 설치 파일을 받아 다시 설치해 보세요.

**저장한 유튜브 영상은 어디에 있나요?**
`%APPDATA%\MP4-Trim\youtube_cache` 폴더에 있습니다. 탐색기 주소창에 그대로 붙여 넣으면 열립니다. 용량이 커지면 이 폴더의 파일을 지우면 됩니다.

**프로그램을 지우면 내 동영상도 지워지나요?**
아니요. 프로그램만 지워지고 동영상 파일과 잘라 낸 결과물은 그대로 남습니다.

## 🛠️ 개발자용

<details>
<summary>소스에서 실행·빌드하기</summary>

필요한 것: Python 3.12, `pip install PyQt6 yt-dlp pyinstaller`, PATH에 FFmpeg

```
python movie-player-lite.py      소스에서 바로 실행
.\run-dev.bat                    실행 중인 앱을 끄고 → 다시 빌드 → 실행
.\build-installer.bat            설치 파일 만들기 (Inno Setup 6 필요)
```

- 설치 파일은 `installer_output\MoviePlayerLite-Setup.exe`로 만들어집니다. 이 파일을 GitHub 릴리스에 같은 이름으로 올리면 이 문서의 내려받기 링크가 최신 버전을 가리킵니다.
- 설치 파일에 표시되는 버전은 `VERSION.md`의 가장 위 항목에서 읽어 옵니다.
- **언어 추가**: `locales/en-US.json`을 `locales/<언어코드>.json`으로 복사해 번역하고 `_meta.name`에 표시 이름을 적으면 메뉴에 자동으로 나타납니다.

```
src/core/       핵심 로직 (자르기·메타데이터, 단축키, 다국어, 유튜브)
src/ui/         화면 (메인 창, 플레이어·타임라인 위젯, 대화상자)
locales/        언어별 번역 파일
installer.iss   설치 프로그램 스크립트
```

</details>
