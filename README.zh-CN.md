# 🎬 Movie Player Lite

[English](README.md) | [한국어](README.ko.md) | **简体中文** | [日本語](README.ja.md) | [Español](README.es.md) | [Português](README.pt-BR.md) | [Deutsch](README.de.md)

一款免费的 Windows 视频播放器，可以**瞬间无损地剪下你需要的那一段**。

---

## ⬇️ 下载与安装

### 👉 [下载 Movie Player Lite 安装程序（Windows 10 / 11）](https://github.com/iseohyun/movie-player-lite/releases/latest/download/MoviePlayerLite-Setup.exe)

1. **点击上面的链接。** 会下载一个名为 `MoviePlayerLite-Setup.exe` 的文件。
2. **双击下载好的文件。** 它通常在“下载”文件夹里。
3. 如果出现蓝色的 **“Windows 已保护你的电脑”** 窗口，请点击 **更多信息** → **仍要运行**。
   这是 Windows 对个人制作的程序显示的提示，并不表示程序有问题。
4. 选择语言，然后一直点击 **Next（下一步）**。中间出现的选项保持默认即可。
   安装界面目前没有中文，会显示英文；程序本身支持简体中文。

   | 选项 | 说明 |
   | :--- | :--- |
   | 安装文件夹 | 没有特别需要就不用改。 |
   | 创建桌面快捷方式 | 想在桌面上放图标就勾选。 |
   | 默认播放的文件类型 | 勾选的类型（如 `.mp4`）双击后会用本程序打开。 |
   | 下载最新的 FFmpeg | **请保持勾选。** 它会自动下载剪切和保存 YouTube 视频所需的组件。如果电脑里已经有了，这一项不会出现。 |

5. 点击 **Install（安装）**，等待完成后点击 **Finish（完成）**，程序就会启动。

- 不需要管理员权限。适用于 64 位 Windows 10 / 11。
- **卸载方法**：打开 Windows“设置”→“应用”→“已安装的应用”，找到 **Movie Player Lite**，点击“卸载”。

## 🎞️ 能做什么

- **超高速无损剪切** — 不重新编码，很长的视频也只需几秒。
- **旋转或翻转画面后保存**、**把当前画面保存为截图**
- **在画面上绘图** — 画笔痕迹稍后会自动消失，讲解时很方便。
- **用 YouTube 地址播放** — 第一次直接在线播放，之后播放已保存的文件。
- **播放速度、缩放与移动、逐帧移动、播放列表**
- **7 种语言** — 한국어、English、简体中文、日本語、Español、Português、Deutsch

## 🚀 第一次使用

**打开视频**
把视频文件拖到程序窗口里。或者在画面上点击鼠标右键，选择“文件”→“打开”。

**剪下想要的片段**
1. 按 `E` 键打开编辑窗口。
2. 拖动下方时间线上的**两条绿线**，设定开始和结束位置。
3. 点击 **剪切** 按钮。原文件保持不变，会生成一个新文件。

**观看 YouTube 视频**
按 `Ctrl + U`，粘贴 YouTube 地址。请只用于你有权观看的视频。

**显示菜单**
按 `Alt` 键，或在画面上点击鼠标右键。菜单项右侧会显示对应的快捷键。

## ❓ 常见问题

**出现“Windows 已保护你的电脑”窗口。**
这是 Windows 对没有使用付费证书签名的程序显示的提示。点击 **更多信息** → **仍要运行** 即可安装。

**FFmpeg 是什么？一定要下载吗？**
它是一个用来剪切和合并视频的免费工具。没有它也可以播放视频，但无法剪切和保存 YouTube 视频。安装时保持勾选就会自动下载。

**YouTube 视频打不开。**
YouTube 改版后可能会暂时无法使用。请从上面的链接下载最新的安装程序并重新安装。

**保存的 YouTube 视频在哪里？**
在 `%APPDATA%\MP4-Trim\youtube_cache` 文件夹中。把这段路径粘贴到文件资源管理器的地址栏即可打开。占用空间太大时，删除其中的文件即可。

**卸载程序会删除我的视频吗？**
不会。只会删除程序本身，你的视频文件和剪切出来的片段都会保留。

## 🛠️ 开发者

<details>
<summary>从源代码运行和构建</summary>

需要：Python 3.12、`pip install PyQt6 yt-dlp pyinstaller`，以及 PATH 中的 FFmpeg

```
python movie-player-lite.py      从源代码直接运行
.\run-dev.bat                    关闭正在运行的程序 -> 重新构建 -> 启动
.\build-installer.bat            生成安装程序（需要 Inno Setup 6）
```

- 安装程序生成在 `installer_output\MoviePlayerLite-Setup.exe`。把它以相同的名字上传到 GitHub Release，本文档中的下载链接就会指向最新版本。
- 安装程序显示的版本号取自 `VERSION.md` 最上面的条目。
- **添加语言**：把 `locales/en-US.json` 复制为 `locales/<语言代码>.json` 并翻译，在 `_meta.name` 中填写显示名称，菜单中会自动出现。

```
src/core/       核心逻辑（剪切与元数据、快捷键、多语言、YouTube）
src/ui/         界面（主窗口、播放器与时间线控件、对话框）
locales/        各语言翻译文件
installer.iss   安装程序脚本
```

</details>
