# 🎬 Movie Player Lite

[English](README.md) | [한국어](README.ko.md) | **简体中文** | [Español](README.es.md) | [Português](README.pt-BR.md) | [Deutsch](README.de.md)

## 📌 项目概述与目的
- **Movie Player Lite** 是一款超高速无损视频播放器与分割工具，可避免在编辑大容量高画质视频时因时间线重新编码而造成的时间与画质损失。
- 通过**基于 FFmpeg 的无损（Stream Copy）超高速剪切功能**，瞬间无损提取所需的有效区间。

---

## 🔥 主要功能与用法

### 1. 内置视频播放器与时间线滑块
- **内置视频播放器**：搭载 QMediaPlayer，支持通过单击/双击/鼠标悬浮层进行播放/暂停/全屏
- **异步提取 10 个场景的缩略图时间线**：一眼掌握整段视频走向的胶片式时间线
- **1px 竖线智能标记**：剪辑起点/终点（1px 绿色竖线）与当前播放位置（1px 红色竖线）始终绘制在最上层
- **智能暂停**：播放中用鼠标按住或拖动进度条时自动暂停，便于精确操作

### 2. 选项、历史与播放列表侧边栏
- **左侧选项面板 (`[`)**：静音、复制拍摄属性、自动编号，以及相同/output/自定义保存路径选择
- **自定义快捷键面板 (`⌨`)**：可自行修改并保存主快捷键与备用快捷键 (`hotkeys.json`)
- **右侧播放列表面板 (`]`)**：管理最近的视频、添加文件/拖放、按 Delete 移除项目或清空全部、自动清理已丢失的文件 (`playlist_history.json`)
- **平滑的滑动动画**：按下快捷键时侧边栏以优化的滑动方式开合

## ⌨️ 默认快捷键

| 功能 | 主快捷键 (Primary) | 备用快捷键 (Secondary) |
| :--- | :---: | :---: |
| **切换选项面板** | `[` | - |
| **切换播放列表** | `]` | - |
| **播放 / 暂停** | `Space` | `K` |
| **后退 / 前进 1 秒** | `Left` / `Right` | `J` / `L` |
| **后退 / 前进 5 秒** | `Shift + Left` / `Shift + Right` | - |
| **后退 / 前进 1 帧** | `Ctrl + Left` / `Ctrl + Right` | - |
| **切换 / 退出全屏** | `F`（或 `F11`） | `Esc` |
| **查看视频详细信息** | `?` (Shift + `/`) | - |
| **删除播放列表项** | `Delete` | - |

## 🌐 语言设置
- 在 **设置 → 语言** 菜单中选择 `系统语言`（默认）或任意已安装的语言。更改将在**重新启动程序后**生效。
- 内置语言：한국어、English、简体中文、Español、Português (Brasil)、Deutsch。如果系统语言没有对应的翻译，则显示英语。
- **添加语言**：将 `locales/en-US.json` 复制为 `locales/<语言代码>.json`（例如 `fr-FR.json`），翻译其中的值，并在 `_meta.name` 中填写显示名称，然后把 `locales` 文件夹放在可执行文件旁边，菜单中会自动出现该语言。

## 📁 项目文件结构

```
mp4-trim
├ src/
│  ├ core/                  # 核心逻辑（FFmpeg 剪切、元数据/属性提取、自定义快捷键、多语言 i18n）
│  ├ ui/                    # UI 组件与对话框
│  │  ├ widgets/            # 自定义时间线、视频播放器、时间输入控件
│  │  ├ dialogs/            # 快捷键指定对话框
│  │  └ main_window.py      # VideoCutterApp 主窗口布局与事件关联
│  └ utils/                 # 异常日志弹窗与时间格式转换工具
├ locales/              : 各语言翻译文件 (ko-KR.json, en-US.json, ...)
├ icon.ico              : 程序主图标
├ MP4-Trim image.png    : README 截图
├ build.bat             : 独立可执行文件构建脚本（轻量版 / 完整包）
├ mp4-trim.py           : 程序入口 (Main Entry Point)
├ README.md             : 使用说明与项目信息
└ .gitignore            : Git 忽略规则文件
```

## 🛠️ 准备 FFmpeg（必需）
1. **下载 FFmpeg**：[Gyan.dev 官方网站](https://www.gyan.dev/ffmpeg/builds/)
2. 解压 `ffmpeg-release-essentials.zip` 后，将 `bin/ffmpeg.exe` 复制到本项目文件夹，或将其加入系统 **PATH**。
